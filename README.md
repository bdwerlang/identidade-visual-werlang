# Identidade Visual Werlang

Acervo da marca Werlang para uso em materiais digitais, peças impressas e uniformes. Consulte o [Manual de Identidade Visual](Manual%20de%20Identidade%20Visual%20Werlang.pdf) antes de aplicar a marca.

| Material | Onde encontrar |
| --- | --- |
| Logotipos | [Horizontal](Marca/Horizontal), [sem tagline](Marca/Sem%20Tagline) e [com tagline Suinocultura](Marca/Tagline%20Suinocultura), com versões em SVG e PNG |
| Arquivos-mestre da marca | [AI, EPS e PDF](Marca) |
| Gradientes | [Arquivos PNG](Gradientes) |
| Imagens | [Arquivos PNG](Imagens) |
| Tipografia | [Zalando Sans](Fontes) em TTF, com versões variáveis e estáticas, sob a [licença SIL Open Font License](Fontes/OFL.txt) |
| Cartão de visitas | [Arquivos AI, EPS e PDF](Cart%C3%A3o%20de%20Visitas) |
| Uniformes | [Visitante](Uniforme/Uniforme%20Visitante%20-%20Laranja), [fiscal](Uniforme/Uniforme%20Fiscal%20-%20Azul%20Claro) e [operacional](Uniforme/Uniforme%20Operacional%20-%20Azul%20Escuro), com prévias, editáveis e arquivos de impressão |

Para aplicações digitais, use SVG quando o formato for aceito e PNG quando precisar de uma imagem raster. Para impressão, confira o manual e escolha o arquivo de impressão correspondente à peça.
